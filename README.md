# grao

Galeria pessoal de fotos em estilo minimalista (inspirada em feeds VSCO), entregue por um único servidor Node.js.

## Recursos

- SSR com React (`react-dom/server`) no endpoint `/`
- API JSON no endpoint `/api/photos`
- Arquivos de imagem servidos estaticamente em `/images/*`

## Como rodar

```bash
npm install
npm start
```

Acesse `http://localhost:3000`.

## Testes

```bash
npm test
```
